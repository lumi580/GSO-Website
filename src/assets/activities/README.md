# Activity photos

Drop GSO event photos (`.jpg`, `.jpeg`, `.png`, `.webp`) in this folder and
they appear in the homepage "Moments" gallery automatically: no code changes.

- The file name becomes the caption: `graduate-orientation-2026.jpg` →
  "Graduate Orientation 2026".
- Prefix with a number to set the order: `01-team.jpg` shows first and the
  number is left out of the caption.
- Keep each photo under ~500 KB (about 1600px on the long side).
- Only use photos the GSO has permission to publish.
